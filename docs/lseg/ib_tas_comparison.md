## 目标与数据源

比较 IB（Interactive Brokers，盈透证券）的分钟 K 线与本项目 TAS 数据质量，输出可按工具和日期追溯的差异明细与汇总。

| 项目 | 配置 |
| --- | --- |
| 数据库类型 | MySQL |
| 主机 | `10.61.20.11` |
| 端口 | `3306` |
| 数据库 | `ib_data` |
| 用户名 | `ib_reader` |
| 期货分钟表 | `minute_data` |
| ETF 和股票分钟表 | `minute_data_stock` |

用户提供的连接信息已保存在本机 `.env.local` 的 `IB_MYSQL_*` 变量中；该文件已加入 `.gitignore`。比较程序读取配置，不将密码写入代码或运行报告。IB 数据库只读使用，结果写独立目录。

TAS 参考源为既有全品种 RocksDB，以及已验收的 2026 年 1–5 月 Trade / Quote Parquet。格式和路径见 [TAS Parquet](tas_tick_parquet.md)。期货成交 K 线应由对应真实到期合约的 TAS Trade 按确认口径聚合；Quote 只有既有 1 秒 BBO，可用于相应报价指标的核对。库中指数、连续报价、真实到期合约须按各自身份处理。

## 执行时先确认的口径

- 先读取两表结构、工具标识和日期覆盖，确认实际字段、时间单位、时区、分钟时间戳代表起点还是终点，以及 K 线类型（成交、报价或其它）。
- 核对 IB 合约标识与 TAS 原始 RIC、交易所、币种、到期月份的对应关系；连续合约与固定到期合约分别匹配。不能仅按品种简称拼接不同合约。
- 统一分钟边界、交易日、全天或常规交易时段、无成交分钟处理、价格缩放、数量单位、成交范围及修订处理。TAS 当前价格为 `×1e9` 定点整数。
- `minute_data_stock` 的比较须先确认对应股票 / ETF 的 TAS 来源与标识映射。当前海外期货 TAS 包中混有的指数点位不作为股票 / ETF 成交数据的替代。

## 初始比较维度

- 日期和分钟覆盖：缺日、缺分钟、额外分钟、重复主键、无效值。
- K 线一致性：开、高、低、收及成交量；均价、成交笔数等仅在双方字段和定义确认一致后比较。
- 异常检查：时间错位、价格跳变、价格或数量缩放差异，以及 OHLC 自身约束。
- 差异定位：保留合约身份、UTC 分钟、双方原值、绝对差和相对差，并关联 TAS 源记录以便复查。

差异报告须区分口径差异、覆盖缺口和待核实异常；仅凭 IB 与 TAS 数值不同，不直接判定哪一方错误。
