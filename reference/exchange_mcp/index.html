其他用户如何开始

  1. 先打开数据：国内 IF 合约 JSON，或 CME ES 合约 JSON。浏览器即可查看，无需安装软件。

有什么数据

这里只提供已采集的参考数据与历史状态，不提供实时行情或订单执行。

国内期货 · CN

六家交易所合约规格、手续费及保证金参考、连续竞价时段、已采集公告和申报费规则。

OpenCTP 属于经纪商参考数据。时段为基础模板，历史精确度取决于已采集版本。

海外期货 · CME

ES、NQ、RTY、YM、GC、CL 的历史定义、状态事件、官方历史交易时段，以及海外经纪商佣金参考。

状态事件按 UTC 接收日期查询；官方交易日按芝加哥时区。佣金保留原始收费口径。
数据集范围 / 更新日期数据口径
CN 合约、手续费、保证金点击“刷新数据范围”查询实时覆盖六家交易所、逐合约版本；可能保留已到期合约，每条记录的 sourceDate 可能早于全局最新日期。
CN 连续竞价时段按交易所与品种查询；响应自带 dataState上海时区的基础模板，不包含完整节假日规则。
CME 历史合约定义ES / NQ / RTY / YM / GC / CLDatabento GLBX.MDP3，UTC 当日结束时已观测的单腿期货定义。
CME 股指状态事件ES / NQ / RTY / YM；实际范围以数据统计为准按 UTC 接收日期查询，包含开收盘、停盘、禁撤等事件。
CME 商品状态事件GC / CL；实际范围以数据统计为准午夜快照会显式标记，不等于真实状态切换。
CME 官方历史时段六个品种；按起止交易日查询，一次最多 366 天Chicago 交易日，开收盘时间返回 UTC，保留来源和分段；空结果不能单独证明休市。
海外经纪商佣金按关联代码或交易所查询；包括 CME Group 及其他海外市场保留币种、版本及有效期。收费方向未指定时不能自行解释为单边或往返。
CN 公告 / 申报费规则已采集公告与已保存规则；默认只查询已审核规则无数据返回空数组；只有 VERIFIED 规则可执行。

全部 12 个接口与数据字段

HTTP 接口和 MCP 工具使用相同参数。点击“参数与字段”展开说明，点击“真实数据”直接查看 JSON。可选参数不传即使用默认值。

日期使用 YYYY-MM-DD；布尔参数使用 true / false。分页接口最多每页 200 条，先读 total 与 pages，再按 page=1、2、3 依次取完。HTTP 400 表示参数错误，502/503 表示数据源暂不可用。

Python：读取 CN 与 CME 数据（仅标准库）

import json
from urllib.parse import urlencode
from urllib.request import urlopen

BASE = "http://127.0.0.1:8780"

def query(tool, **params):
    url = BASE + "/api/" + tool + "?" + urlencode(params)
    with urlopen(url, timeout=65) as response:
        return json.load(response)

cn = query("cn_instruments", venue="CFFEX", product="IF", page_size=2)
for row in cn["records"]:
    print(row["instrumentId"], row["priceTick"], row["fees"])

page = 1
while True:
    cme = query("cme_definitions", product="ES", page=page, page_size=50)
    for row in cme["records"]:
        print(row["raw_symbol"], row["min_price_increment"], row["tick_value"])
    if page >= cme["pages"]:
        break
    page += 1

在支持远程 MCP 的客户端中选择 Streamable HTTP，填入：

同机访问使用 http://127.0.0.1:8780/mcp。同机其他用户可直接连接，无需登录。


MCP 地址需要填入客户端的连接配置。浏览器直接打开时会显示本说明页；网页查询请使用下方表单。

客户端通过 tools/list 发现 12 个工具；通过 resources/list 可发现使用说明和字段目录，分别为 exchange-reference://guide 与 exchange-reference://catalog。其他客户端请按其远程 HTTP MCP 配置格式填写上方 URL。
